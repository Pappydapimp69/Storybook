# There's Someone in the Box

An interactive picture book about a real text scam. Tap to start; the story stops at three choices and your taps change the ending.

Play it: https://pappydapimp69.github.io/Storybook/

Every line marked REAL TEXT is copied from a real scam thread (Nov 2026). MASIS Staffing and Merchkit are real companies whose names the scam borrowed. Sound uses a procedural Web Audio engine (`book/engine/`).

Report scam texts: forward to 7726 · reportfraud.ftc.gov · ic3.gov
